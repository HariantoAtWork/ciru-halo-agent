Clear stale `optimized-runtime/<pid>` audit dirs on every Ciru start.

Ornith's worker creates those dirs with `exist_ok=False`, so container/host restarts that reuse low PIDs crashed with `FileExistsError` during `load_model`. The entrypoint (and host serve launcher) now wipe leftovers before launch; compose also mounts the fixed entrypoint so the running image picks it up without a rebuild.
